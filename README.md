# testgolang

Script Go d'expérimentation qui s'authentifie auprès de l'API UiPath Orchestrator (OAuth client credentials) et récupère la liste des jobs, exportée dans un fichier local.

## Stack

- Go
- API UiPath Orchestrator

## Note

Le script contient des identifiants d'API d'exemple codés en dur, à ne pas réutiliser : à remplacer par une configuration externe (variables d'environnement) avant tout usage réel.
